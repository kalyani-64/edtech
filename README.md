# edtech
this is a website where student and teacher have to login ,the teacher will assign task to the students.In the website there will be update about the task done by the student. 
to run this project we need to have node.js for both backend and frontend.
to run frontend folder the steps are 
step:1:-open terminal run 'npm install'
step:2:-after that run'npm start'
to run backend the first step is same but second command is 'npm run dev'
to check the database go to command prompt and run 'mongosh'
next use the database i named it as edtech, so the command will be 'use edtech'
next command is'show collections'
to see the data in the database the database 'db.users.find().pretty()
